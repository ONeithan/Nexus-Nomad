# Guia Prático e Visual do Multímetro Digital de Campo

### As 5 Escalas Vitais:
1. **DCV 20V:** Para testar baterias 12V (`12,7V = 100%`, `12,2V = 50%`, abaixo de `11,8V = crítico`).
2. **ACV 750V:** Para tomadas 110V/220V e saídas de inversores.
3. **Continuidade (Bip):** Para achar fios rompidos e curtos-circuitos.
4. **Resistência (Ohms):** Para medir resistores e elementos térmicos.
5. **DCA 10A:** Medição de corrente SEMPRE em série com o circuito. Nunca em paralelo!
