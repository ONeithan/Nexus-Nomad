# Ferramentas de TI (IT-Tools)

> **Manual Individual de Operação N.O.M.A.D.** — Documento exclusivo do módulo **Ferramentas de TI (IT-Tools)** (`nomad_it_tools`).

- **Identificador do Serviço:** `nomad_it_tools`
- **Porta TCP Padrão:** `8430`
- **Categoria Operacional:** Utilitários
- **Modalidade:** Módulo Nativo N.O.M.A.D.
- **Arquivo de Documentação:** `app-nomad-it-tools.md`

---

## 🔑 Credenciais Padrão & Acesso Inicial

- **Modalidade de Autenticação:** Acesso Direto pela Rede Local (Sem Login Inicial)
- **Usuário / Login Padrão:** `Acesso Direto (Sem login)`
- **Senha Padrão:** `Sem senha inicial`
- **Instruções de Primeiro Acesso:** Esta aplicação abre diretamente no navegador sem exigir login ou senha na primeira utilização.

---

## 🎯 1. Para Que Serve Este Aplicativo

Coleção prática com mais de 70 utilitários para desenvolvedores, técnicos e administradores de sistemas com tradução nativa em português.

---

## ⚙️ 2. Principais Recursos & Capacidades

- Calculadora de sub-redes IPv4/IPv6 e conversor de máscaras CIDR
- Formatador de JSON, XML, SQL e YAML
- Gerador de senhas seguras, chaves SSH e UUIDs v4
- 100% traduzido para Português do Brasil no N.O.M.A.D.

---

## 🧠 3. Como Funciona (Arquitetura & Fluxo de Dados)

Aplicativo estático ultra-otimizado que roda integralmente no cliente web com visual escuro tático, permitindo operações imediatas sem latência de rede.

---

## 💡 4. Exemplo Real de Uso Prático

Calcular em segundos quantos hosts cabem em uma sub-rede /27 ou formatar um JSON desorganizado de uma API para entender o retorno de erro.

---

## 🚀 5. Guia Rápido de Operação & Persistência

- **Endereço de Acesso Direto:** `http://<IP-DO-SERVIDOR>:8430` (ou clique em **Abrir** no card do aplicativo dentro da **Central de Aplicativos**).
- **Execução Local ou Remota (Portainer):** Este serviço pode ser implantado tanto no motor Docker local quanto no **Servidor Portainer Remoto** ativo na tela **Servidores Remotos**.
- **Controle e Manutenção:** Use o menu **Gerenciar** na Central de Aplicativos para iniciar, parar, reiniciar, visualizar logs em tempo real, configurar URL personalizada ou atualizar o contêiner.
