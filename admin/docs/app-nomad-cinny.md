# Cinny (Interface Web Matrix Estilo Discord)

> **Manual Individual de Operação N.O.M.A.D.** — Documento exclusivo do módulo **Cinny (Interface Web Matrix Estilo Discord)** (`nomad_cinny`).

- **Identificador do Serviço:** `nomad_cinny`
- **Porta TCP Padrão:** `8621`
- **Categoria Operacional:** Comunicação
- **Modalidade:** Módulo Nativo N.O.M.A.D.
- **Arquivo de Documentação:** `app-nomad-cinny.md`

---

## 🔑 Credenciais Padrão & Acesso Inicial

- **Modalidade de Autenticação:** Cadastro no Primeiro Acesso / Credencial Global
- **Usuário / Login Padrão:** `Criar conta no 1º acesso`
- **Senha Padrão:** `Definir senha no 1º acesso`
- **Instruções de Primeiro Acesso:** No primeiro acesso via navegador, o aplicativo exibe um assistente rápido para você cadastrar seu login e senha de administrador.

---

## 🎯 1. Para Que Serve Este Aplicativo

Servidor do protocolo federado Matrix com cliente web Cinny (interface com visual idêntico ao Discord).

---

## ⚙️ 2. Principais Recursos & Capacidades

- Porta padrão mapeada: 8621
- Categoria operacional: communication
- Integração com ecossistema N.O.M.A.D.

---

## 🧠 3. Como Funciona (Arquitetura & Fluxo de Dados)

Criptografia de ponta a ponta nativa (E2EE) onde somente você e o destinatário têm a chave de decodificação das conversas, sem possibilidade de leitura por terceiros.

---

## 💡 4. Exemplo Real de Uso Prático

Utilizado para operações de communication com controle e soberania local no seu homelab.

---

## 🚀 5. Guia Rápido de Operação & Persistência

- **Endereço de Acesso Direto:** `http://<IP-DO-SERVIDOR>:8621` (ou clique em **Abrir** no card do aplicativo dentro da **Central de Aplicativos**).
- **Execução Local ou Remota (Portainer):** Este serviço pode ser implantado tanto no motor Docker local quanto no **Servidor Portainer Remoto** ativo na tela **Servidores Remotos**.
- **Controle e Manutenção:** Use o menu **Gerenciar** na Central de Aplicativos para iniciar, parar, reiniciar, visualizar logs em tempo real, configurar URL personalizada ou atualizar o contêiner.
